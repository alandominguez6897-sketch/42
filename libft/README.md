**Description :**
This project called "Libft" is a folder that contains over 50 files that hold functions. Each file contains 1 "main" function, which is the function that should be used from the outside, the rest are helpers for it. Libft was created to be a personal helper for whenever I (or anybody else) need(s) to fulfill a task in C during a project at 42, or at home. It handles common, repetitive tasks in C projects, doing the heavy lifting so complex workflows feel as simple as few words.
